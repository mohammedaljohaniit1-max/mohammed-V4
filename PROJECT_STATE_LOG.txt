[1] ARCHITECTURAL RE-ENGINEERING & PRODUCTION BENCHMARK MODULES
--------------------------------------------------------------------------------
1. Module 1: Recursive Schema-Driven API Auditor (`pkg/phases/api_schema_auditor.go`):
   - In-memory OpenAPI v2 / v3 & Swagger parser (`/v3/api-docs`, `/swagger.json`, `/openapi.json`).
   - Automatically parses paths, HTTP methods (GET, OPTIONS, POST), and object parameters.
   - Privilege & Broken Authentication Check: filters for sensitive operational route keywords
     (`mgmt`, `admin`, `user`, `delete`, `create`, `token`, `export`, `config`, `internal`).
   - Verifies unauthenticated responses return authentic application/json data rather than login
     prompts or error wrappers, flagging:
     `[High] Broken Authentication / Unprotected Management Endpoint: <url>`.
   - BOLA / IDOR identifier extraction: flags routes containing `{uimUserId}`, `{campaignKey}`, `{id}`.

2. Module 2: JavaScript & Source-Map Deep Harvester (`pkg/phases/js_harvester.go`):
   - Bundle Scraper: extracts all unique in-scope `<script src="*.js">` bundles from landing pages.
   - Secret & Credential Extraction: regex scans for AWS Access Keys (`AKIA[0-9A-Z]{16}`),
     Google API keys (`AIza[0-9A-Za-z-_]{35}`), generic Bearer tokens, and RSA/SSH private keys.
   - Shannon Entropy Validator: enforces entropy floors (>2.8 for AWS, >3.0 for Google, >3.2 for Bearer)
     to discard placeholder test tokens (e.g. `AKIAEXAMPLEKEY12345`).
   - Hidden Internal Route Harvesting: mines routes matching `/api/v[0-9]/...` and appends them
     to target URL state for downstream security inspections.
   - Source-Map Discovery: checks for public `*.js.map` exposures and flags information disclosure.

3. Module 3: Dangling CNAME & Subdomain Takeover Resolver (`pkg/phases/takeover_resolver.go`):
   - DNS CNAME mapping across all discovered subdomains.
   - Cross-references pointers against verified cloud abandonment signatures:
     * AWS S3: `NoSuchBucket`, `The specified bucket does not exist`
     * GitHub Pages: `There isn't a GitHub Pages site here`
     * Heroku: `No such app`, `herokucdn.com/error-pages/no-such-app.html`
     * Azure Traffic Manager & CloudApp: `404 Web Site not found`
     * Zendesk: `Help Center Closed`
     * Fastly / CloudFront: `Fastly error: unknown domain`, `Bad request: ERROR: The request could not be satisfied`
   - Flags confirmed takeovers as `[High] Subdomain Takeover: <subdomain> -> <cname>`.

4. Module 4: Zero-Tolerance Catch-All Purge (`pkg/phases/surgical_probes.go`):
   - Content Invariant & Magic Byte Validation:
     * `/backup.zip`: Enforces ZIP magic bytes (`PK\x03\x04`).
     * `/.env` & `/.env.production`: Enforces `^(APP_KEY|DB_PASSWORD|SECRET_KEY|DATABASE_URL|AWS_SECRET_ACCESS_KEY)=`.
     * `/.git/HEAD`: Enforces exact header match `ref: refs/heads/` or `ref: refs/`.
     * `/.git/config`: Enforces `[core]` and `repositoryformatversion`.
     * `/.htpasswd`: Enforces Apache crypt, apr1, or bcrypt regex format.
   - Silent Discard: If a 200 OK response fails its content invariant, it is immediately dropped
     and never recorded as Info or High.

5. Module 5: High-Speed IP-Deduplicated Port Scanner (`pkg/phases/light_portscan.go`):
   - IP Deduplication: Resolves all live subdomains to underlying IPv4 addresses and deduplicates
     edge anycast IPs (e.g., 1000 subdomains resolving to 4 Akamai anycast IPs are scanned only once).
   - Asynchronous Connect Pool: 20 concurrent dialers scanning Top-100 web/admin ports
     with a 500ms socket timeout. Complete run finishes in under 2 minutes.
   - Maps open ports back to virtual hostnames for HTTP verification.

6. Core Safety Governor (`pkg/governor/governor.go`):
   - Strict rate-limiting (<= 2 req/s default), concurrency semaphore (cap = 2), and jitter (150-300ms).
   - Autonomous Target Capacity Sensing (`AutoDetectTargetCapacity` / `DetectTargetCapacity`):
     dynamically tunes rate limit and concurrency based on RTT latency and CDN fronting.
   - Automated Circuit Breaker on 429/503/504 errors with exponential backoff.

7. Report Hygiene & Sanitization Engine (`pkg/report/exporter.go` & `pkg/phases/phases_vuln.go`):
   - Strict `IsReportableFinding(f)` filter: completely excludes internal pipeline milestones
     (Target Classification, Autonomous Session Bootstrap) from vulnerability tables.
   - Zero `<nil>` artifacts across Markdown and text reports.
