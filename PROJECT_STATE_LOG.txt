[1] ARCHITECTURAL IMPLEMENTATION HIGHLIGHTS
--------------------------------------------------------------------------------
1. Core Safety Governor (`pkg/governor/governor.go`):
   - Strict rate-limiting hard cap (<= 2 req/s) with safe enterprise defaults.
   - Concurrency semaphore strictly bounding simultaneous network workers (cap = 2).
   - Dynamic jitter (200-400ms) to avoid predictable traffic spikes.
   - Automated Circuit Breaker: triggers on HTTP 429 (Too Many Requests), 503 (Service Unavailable),
     and 504 (Gateway Timeout), backing off exponentially before re-evaluating in half-open state.
   - Comprehensive `http.RoundTripper` and `http.Client` wrapper (`WrapClient`, `WrapTransport`)
     guaranteeing no network request escapes governance.
   - Verified with race detector: `go test -v -race ./pkg/governor/...` PASSED.

2. Zero-Touch Passive OSINT (`pkg/osint/domain_recon.go`):
   - 100% external passive reconnaissance: queries public aggregators without sending a single packet to the target server.
   - Certificate Transparency log collection via crt.sh JSON API with deduplication.
   - Historical endpoint mining via Wayback Machine and AlienVault OTX Passive DNS.
   - Passive DNS and CNAME mapping via public DNS resolvers (Cloudflare 1.1.1.1 / Google 8.8.8.8)
     for dangling subdomain takeover identification.
   - Isolated `DomainAssetBundle` struct decoupled from identity modules.
   - Verified with mock HTTP tests: `go test -v -race ./pkg/osint/...` PASSED.

3. False-Positive Elimination Layer (`pkg/validation/baseline_validator.go`):
   - Dynamic Soft-404 baseline calibration: probes a non-existent randomized path (`/.calib-<uuid>`)
     to fingerprint catch-all status codes, content lengths, body hashes, and HTML titles.
   - Strict length tolerance (±64 bytes) and hash matching to reject wildcard 200 OK responses.
   - Exact token and regex verification (`ExactTokenCheck`): enforces `APP_KEY=` for `.env`,
     `[core]` / `ref: refs/heads/` for `.git`, and `{"status":"UP"}` JSON structure for Spring Boot Actuator.
   - Rejects `text/html` responses claiming to be raw config or credential files.
   - Verified with test suite: `go test -v -race ./pkg/validation/...` PASSED.

4. Fuzzer Parameter Bloat Elimination (`pkg/filter/param_filter.go`):
   - Implemented `ShouldSkipFuzzParam(paramName)` and `ShouldSkipFuzzURL(rawURL)`.
   - Filters out CMS pagination & navigation keys (`page`, `p`, `pno`, `paged`, `pg`, `offset`, `limit`, `size`).
   - Filters out static display and language keys (`lang`, `hsLang`, `language`, `category`, `article`, `sort`, `order`).
   - Filters out analytics & tracking keys (`utm_*`, `pk_*`, `ga_*`, `_hs*`, `gclid`, `fbclid`).
   - Integrated into Phase 63 (Adaptive Fuzz) via `sanitizeFuzzURLs` helper, preventing fuzzer timeouts and false-positive SQLi alerts.

5. Early Staging & Internal Asset Prioritization (`pkg/filter/subdomain_priority.go`):
   - Implemented `PrioritizeLiveTargets(hosts []string)`.
   - Naturally floats staging, dev, uat, test, internal, admin, and api subdomains to the front of the host list.
   - Pushes root apex and generic `www` to the end of the slice.
   - Applied directly in DNS resolution (`DNSResolvePhase`) and HTTP probing (`HTTPProbePhase`) so all downstream phases naturally test high-yield targets first without modifying the 65-phase architecture.

6. Native Surgical Probes (`pkg/phases/surgical_probes.go`):
   - Direct, pure-Go, single-request checks for exposed `.env`, `.git/HEAD`, `.git/config`, `/actuator/health`, `/swagger-ui.html`, and `/web.config`.
   - Fully governed under concurrency <= 2 and minimum 500ms pacing interval via `EnterpriseSafeGovernor`.
   - Requires zero external heavy tool dependencies.

7. Lightweight Top-100 Web/Admin Port Scanning (`pkg/phases/light_portscan.go`):
   - Pure-Go non-destructive port scanner probing the curated Coffinxp Top 100 web/admin/diagnostic ports (e.g., 80, 443, 8080, 8443, 3000, 5000, 9000, 9443).
   - Resolves and probes only verified live targets (prioritized staging/dev first).
   - Strictly bounded concurrency (semaphore <= 2) and rate-governed (<= 2 req/s) with 2s socket connect timeout.
   - Strictly eliminates 65535 full port sweep DoS risks.

8. Curated Surgical Templates (`pkg/phases/curated_templates.go`):
   - Quality-over-quantity vulnerability inspection hard-capped at <= 30 targeted checks.
   - Categorized into RCE/Known CVEs (e.g. Apache Path Traversal, Spring4Shell, Palo Alto GlobalProtect, PHPUnit), Exposed Sensitive Files, and Unauthenticated Admin/Diagnostic Panels.
   - Dual-layer execution: native Go HTTP baseline-calibrated checks with Soft-404 rejection and exact token signatures + optional rate-limited curated Nuclei fallback (`-tags cve,rce,exposure -rate-limit 50 -concurrency 2`).

9. Explicit CLI Profiles in cmd/preset & cmd/mohammed:
   - Profile `stealth-audit`: Passive OSINT + Safe surgical checks (Rate <= 2 req/s, threads <= 2).
   - Profile `full-assault`: Top-100 port scan + Curated CVE/Exposure templates + Parameter fuzzing (Rate <= 10 req/s with dynamic backoff, threads <= 10).
   - Integrated across `cmd/preset/main.go`, `cmd/mohammed/main.go`, and `pkg/scope/engine.go`.
